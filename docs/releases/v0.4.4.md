# Agentic Project Kit v0.4.4

Installable release. v0.4.4 adds optional manual packaged reasoning skills, explicit two-axis
review presentation, repro-first bugfix guidance, and advisory context-hygiene estimates in
`apk lint`, plus release-safety corrections for Go test discovery and the normal-default generated
artifacts. Behavior outside these changes is unchanged.

## What changed in v0.4.4

- Optional manual packaged skills (plain Markdown assets shipped in the package, never
  auto-activated, never gating, no new CLI):
  - `apk-task-grill` clarifies one existing task before implementation (Task 0123).
  - `apk-task-split` decomposes a named target into proposed vertical-slice tasks (Task 0129).
  - `apk-prototype` runs one bounded throwaway feasibility experiment (Task 0132).
  - `apk-milestone-semantic-audit` audits cross-contract semantic consistency of completed tasks
    (Task 0127).
- One prepared review now presents Spec correctness and Engineering quality explicitly, with
  axis-labelled findings and one conservative Overall outcome (Task 0130).
- The `bugfix` typed template defaults to repro-first guidance with honest best-effort limits
  (Task 0128).
- `apk lint` reports advisory read-only context-hygiene estimates and conservative repetition
  findings; these never set `hasErrors` or gate completion (Task 0131).
- Release-safety corrections: canonical Git-ignore semantics for Go `*_test.go` discovery, with
  `quality.test.ts` now executed by `pnpm test` (Task 0135); regenerated normal-default
  `AGENTS.md`/committed `dist` and a repaired init fixture (Tasks 0134, 0136).

## Compatibility

- Repository-local pinning remains the supported default. No install-time build allowlist is
  needed because `dist/` ships inside the tag.
- Installation does not rewrite existing repositories, customized instructions, or config.
- The optional skills remain manual-only and are not required for ordinary task work.

## Installation

```bash
pnpm add -D git+ssh://git@github.com/HaidaDaniel/AgenticProjectKit.git#v0.4.4
```

HTTPS equivalent:

```bash
pnpm add -D git+https://github.com/HaidaDaniel/AgenticProjectKit.git#v0.4.4
```

`#main` tracks unreleased development; pin a tag for repeatable installs.
