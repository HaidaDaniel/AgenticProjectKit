# Agentic Project Kit v0.4.0

Dogfood release for the completed resource-aware execution and isolated-workspace milestone.

## Major changes since v0.3.1

- canonical `AGENTS.md` common-policy export with thin Claude and Gemini adapters;
- resource-aware model, harness, and worker registry plus execution profiles;
- adaptive assurance, escalation triggers, and bounded review budgets;
- deterministic resource detection and explicitly applied calibration;
- semantic worker attention and status without process-liveness claims;
- safe isolated APK-managed Git worktrees with ownership and cleanup provenance;
- safer adoption and explicit config migration;
- clean-checkout exact-SHA CI and a stronger candidate-bound release gate.

## Compatibility

- Legacy v0.3.1 repositories remain adoptable.
- Configs with absent `schemaVersion` or `schemaVersion: 1` migrate only through explicit `apk adopt --apply` to `schemaVersion: 2`.
- Old generated Codex, OpenCode, and Cursor policy duplicates can be reported and exact-content generated copies can be cleaned safely; customized files are preserved.

## Pinning

After the annotated tag is published, downstream repositories can pin this release from Git:

```bash
pnpm add -D github:HaidaDaniel/AgenticProjectKit#v0.4.0
```

This release does not claim an npm publication.

## Runtime boundary

External terminal/session runtimes can be used alongside APK. No Herdr dependency or adapter is included.
