# Agentic Project Kit v0.4.9

Pre-tag performance-observability release candidate. This note records facts known before
publication; it does not claim that a `v0.4.9` tag has been published or post-tag validated.

## What changed in v0.4.9

- Task 0205 defines the measurement contract for observed software/tooling wall time. LLM
  generation, model/API waiting, reasoning, user think time, and idle/unobserved gaps remain
  excluded.
- Task 0206 adds an opt-in, local-only profiler with automatic APK invocation capture,
  concurrency-aware subprocess attribution, privacy-preserving schemaVersion 1 JSONL traces,
  `apk perf start|status|stop|report`, and explicit `apk perf exec` wrapping for non-APK tools.
- Task 0207 adds an LLM-free disposable-fixture harness and bounded AgenticProjectKit
  self-dogfood baseline. Its report separates child duration sum from child wall-clock union and
  does not make a Go speed claim from synthetic data.

## Compatibility and support

- This is a patch release with no intended CLI renames. `apkit`, `apk`, and
  `agentic-project-kit` remain aliases for the same CLI entrypoint.
- Profiling is optional and off by default. Normal APK workflows do not require `perf start`, a
  benchmark step, a daemon, a database, a network service, or an LLM.
- Trace data is local operational data under `.agentic/perf/`, ignored by Git and excluded from
  task provenance, candidate hashing, and package payloads. The profiler does not promise
  visibility into arbitrary unwrapped shell commands.
- The current validated installable release remains `v0.4.8` until this candidate passes
  exact-candidate, hosted-CI, immutable-tag, and post-tag validation. The maturity policy makes
  no N-1 support, SLA, response deadline, or fixed maintenance-window promise.
- Tasks 0149 and 0150 remain deferred product-identity work. This release makes no rebrand
  decision.

## Installation

Continue to use the validated tag until publication and post-tag validation complete:

```bash
pnpm add -D agentic-project-kit@git+https://github.com/HaidaDaniel/AgenticProjectKit.git#v0.4.8
```

If publication and post-tag validation succeed, the exact `v0.4.9` tag will become the
reproducible installation target.

## Validation chronology

The release process must run the declared PRE-TAG checks against one frozen candidate SHA,
including exact-SHA hosted Quality, before creating an annotated tag. Actual-tag cold
installation, released package/bin identity, profiler smoke, downstream installation, and
post-release self-adoption are separate POST-TAG checks and belong in a separate delivery
artifact. This note must not be backfilled with those later identities or results.
