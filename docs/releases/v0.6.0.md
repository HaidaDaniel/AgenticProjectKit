# Agentic Project Kit v0.6.0

Status: pre-tag release candidate.

This candidate adds a lightweight document-proposal layer for engineering ideas, research,
experiments, adapter sketches, and future documentation plans. Proposals are Git-tracked Markdown
at `<docsDirectory>/proposals/<slug>.md`, with an opaque stable identity, bounded strict parsing,
explicit operator lifecycle decisions, validated canonical/backlog linkage, and an explicit
proposal-only local Git commit workflow. Proposals are not executable tasks, backlog cards, ADRs,
canonical documents, or verification evidence.

The candidate also completes the final `.agentic` runtime-containment correction: evidence,
baselines, agent/run records, configuration, review/dogfood/work sessions, worker review locks,
workspace records, optional performance traces, init starter files, and `execution calibrate
--apply` refuse a symlinked runtime path before mutation. The earlier corrective tasks 0265-0267
and their provenance audit remain part of the release history.

Validation state: the latest validated tagged release is v0.5.2. This candidate has not been
tagged, pushed as a release, or published. Its local release checks, proposal regression,
performance evidence, and release-readiness record are separate; publication remains blocked until
the required operator decisions on historical Tasks 0256 and 0260 are recorded.

Compatibility: existing task, backlog, provenance, and generated-instruction behavior is
unchanged. Repositories without proposals require no new runtime dependency and perform no
proposal-specific work on ordinary commands.
