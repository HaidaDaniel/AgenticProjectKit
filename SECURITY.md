# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/HaidaDaniel/AgenticProjectKit/security). From the repository's **Security** page, choose **Report a vulnerability** to open the private reporting form.

Please do not publish exploit code, vulnerability details, or other sensitive information in public GitHub Issues. Use the private reporting form so the report is not disclosed publicly.

There is no separate security email, published response-time commitment, fix deadline, or bounty program for this project. Reports will be handled through GitHub's private reporting workflow.

## Supported versions

Agentic Project Kit is a pre-1.0 project under active development. The latest validated, installable release is `v0.4.7`. Prefer the latest validated release when reporting a vulnerability. Older tags are historical artifacts; this project does not publish an N-1 support window, backport commitment, or fixed maintenance period.

See the [maturity and compatibility policy](docs/product/maturity-and-compatibility.md) for the current support boundary.
